### RETAILKART BACKEND PROJECT WITH TYPESCRIPT

1. Project contains the updated code with the typescript type-safe APIs
2. Uses modern architecture to handle api queries.
3. Project contains the modules: Auth, User, Cart, Orders, Payments
4. Project uses Razorpay as the payment method.
5. Project contains centralized error handling using error middleware.
6. Also, the project performs the authorization and authentication using the admin and auth middlewares.
